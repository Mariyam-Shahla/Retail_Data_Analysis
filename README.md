# Retail Sales Analysis

## Overview
This project focuses on analyzing retail sales data using Microsoft Excel to identify sales trends, customer behavior, and business performance through data analysis and visualization techniques.

## Objectives
- Analyze retail sales performance
- Identify high-performing products and categories
- Track revenue trends
- Create visual reports and dashboards

## Tools & Technologies Used
- Microsoft Excel
- Pivot Tables
- Charts & Graphs
- Excel Functions

## Dataset Information
The dataset contains retail sales records including product details, sales amount, customer information, quantity sold, and transaction dates.

## Project Workflow
1. Data Collection
2. Data Cleaning
3. Data Organization
4. Data Analysis
5. Dashboard & Visualization
6. Insight Generation

## Key Analysis Performed
- Total sales analysis
- Product category performance
- Monthly sales trend analysis
- Customer purchase behavior
- Revenue analysis

## Key Insights
- Certain product categories generated higher sales revenue
- Sales performance varied across different months
- Customer purchasing trends highlighted popular products

## Excel Features Used
- Pivot Tables
- Pivot Charts
- IF Functions
- VLOOKUP/XLOOKUP
- Conditional Formatting
- Data Filtering & Sorting
